            Um dataset reúne origens. Congelar produz uma versão imutável.

            Minúsculas e hífens. Aparece nas URLs e não muda depois.

            Adicionar origem

            Aponte para um prefixo do bucket. As imagens são catalogadas sem download — só a listagem é lida.

            Clique numa pasta para entrar. O prefixo pode ser editado à mão — a barra inicial faz parte do nome do objeto neste bucket.

            Congelar versão

            Frames seguidos de um vídeo são quase idênticos: divididos ao acaso, o mesmo instante cai nos dois lados e o mAP sobe sem motivo.

            Recorte (ROI)

            Recorta cada imagem para uma região fixa — aplicada igual no treino, na avaliação e na inferência. Use quando só um alvo, sempre na mesma faixa do quadro, deve ser detectado: o recorte tira os vizinhos idênticos, que senão viram "fundo" e confundem o modelo.

            Novo projeto

            Um projeto tem um vocabulário de classes (o schema). A ordem das classes é o índice do formato YOLO e não muda depois.

            Minúsculas e hífens. Aparece nas URLs e não muda depois.

            Enter também adiciona. A ordem é o índice (0, 1, 2…). Em segmentação, "Dentro de" faz da classe um recorte de uma principal.

            Avaliar

            Mede o artefato contra uma versão congelada (o benchmark): mAP e a latência decomposta (pré / inferência / pós). "Todos os formatos" avalia peso e builds de uma vez para comparar.

            Implantar

            Envia o build para uma máquina. O agente dela puxa o artefato e ativa; o coletor lê do caminho conhecido e passa a usar o novo modelo. Uma máquina roda um modelo por vez.

            Compilar

            Gera o artefato implantável. ONNX é portátil; o engine TensorRT é específico do dispositivo e roda na máquina-alvo — mais rápido, é o que vai para a linha.

            Jetson/linha: FP16 + shapes dinâmicos — o engine usa o mesmo letterbox do .pt e as detecções saem idênticas. DLA exige shape fixo.

            Ajuda

            Pré-taguear

            Roda o modelo sobre as imagens de e devolve caixas como rascunho, para você corrigir. Nunca sobrescreve o que já foi rotulado.

            Novo treino

            O treino roda sobre uma versão congelada — imutável, com divisão treino/validação fixa. É o que torna dois treinos comparáveis.

            O treino vira uma nova versão deste modelo. Digite um nome novo para criar outro modelo (ex.: "classificador-defeito").

            Agrupa treinos que você compara entre si (ex.: "baseline", "mais-dados", "aug-forte").

            Deixe no pool para a primeira máquina livre pegar. Escolha uma máquina para fixar o treino nela — se estiver ocupada, o job espera ela liberar.

            Cadastrar máquina

            Cada máquina que executa jobs — um servidor de GPU, um dispositivo de borda — é cadastrada aqui. O que ela pode fazer decide quais jobs recebe.

            Marque tudo que esta máquina pode fazer — ela recebe jobs de qualquer função marcada. O agente acrescenta o diagnóstico (GPU, CUDA) sozinho.
